# Telegram Bot — Личный кабинет для команды

Бот с интерфейсом личного кабинета, странами (пока только Украина), реферальной системой, кошельком и админ-панелью.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` (пример в `.env.example`):
```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_telegram_id
DB_PATH=bot.db
```

3. Запустите бота:
```bash
python main.py
```

## Возможности

- 📋 Главное меню с личным кабинетом
- 🌍 Страны (только Украина) + создание ссылок
- 🔗 Управление ссылками
- 🤝 Реферальная система
- 💰 Кошелёк
- 🆔 Профили
- 🔒 Админ-панель (начисление профита, рассылка, список пользователей)

## Добавление других стран

Отредактируйте файл `keyboards.py` — функция `countries_menu()`.
